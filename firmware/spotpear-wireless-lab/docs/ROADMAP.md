# Spotpear roadmap

- V0.1: isolated build, USB commands for Wi-Fi scan, BLE scan, controlled SoftAP and own BLE advertisement.
- V0.2: verify actual Spotpear PCB/pin map; LCD GC9A01, button GPIO, screen inversion and safe recovery.
- V0.3: microSD logs/CSV/PCAP where supported; test radio coexistence and stop latency.
- V0.4: on-device round UI; no unsolicited TX at startup; explicit Start/Stop.
- V1: QA on physical board, signed artifacts/checksums and release only after acceptance tests.

Never automatically publish a compiled experimental image to the existing XiaoZhi OTA/web-flasher.
